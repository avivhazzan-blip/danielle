# דניאל סביר חזן — גרסה מותאמת להדמיה המאושרת

העמוד הראשי נבנה מחדש לפי ההדמיה בגווני המרווה, עם שימוש בחיתוכי התמונה המאושרת לשמירה על דמות דניאל, הילד ותמונות הבלוג. התוכן, הכפתורים והטפסים בנויים ב־HTML/CSS/JavaScript אמיתיים ולא כתמונת אתר אחת.

## פתיחה

חלצו את הקובץ בשלמותו ופתחו `index.html` בדפדפן. השאירו את תיקיות `assets`, `blog`, `about`, `autism-parent-guidance`, `privacy` במקומן. ניתן להריץ גם שרת מקומי: `python -m http.server 8000`.

## פרסום ו-SEO

החליפו מידע זמני בפרטי קשר אמיתיים, דומיין ותוכן מאושר מקצועית. באתר יש מבנה סמנטי, עמוד בלוג, 4 מאמרים ועמודי התמחות ואודות. לאחר בחירת דומיין, ייצרו גרסת פרסום עם Canonical, JSON-LD, robots.txt ו-sitemap.xml:

`SITE_URL=https://your-domain.co.il node build.mjs`

התיקייה `dist/` מיועדת להעלאה לשרת. אין חובה להפעיל JavaScript כדי לקרוא את התכנים העיקריים.

## תמונות

התמונות של דניאל הן **עיבוד AI על בסיס התמונה שסופקה**, שנחתכו מההדמיה המאושרת. אלו אינם צילומים מקוריים, והחיתוכים נשענים על רזולוציית ההדמיה. להפקה באיכות גבוהה יותר ולפרסום אמיתי רצוי להחליף אותם בצילום מקצועי בעל אותם יחס־ממדים ותאורה.

## טופס יצירת קשר

הטופס כרגע **הדגמתי ואינו שולח פרטים**, כדי שלא להמציא כתובת אימייל או מספר טלפון. חיבור מאובטח לשליחה יתבצע לאחר מסירת פרטי הקשר והתאמת מדיניות הפרטיות.

## התאמת העיצוב

`assets/css/pixel.css` אחראי על העמוד הראשי המותאם להדמיה; `assets/css/styles.css` משמש את עמודי התוכן הנוספים. העיצוב נבדק בתצוגה של 1440px ו־390px. צפיפות תמונה ומרווחים שונים מעט בין דפדפנים, ומומלץ לבצע QA על מכשירים אמיתיים לפני פרסום.
