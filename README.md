# דניאל סביר חזן — אתר הדרכת הורים בגווני מרווה

אתר סטטי, רספונסיבי בעברית RTL: דף בית, עמוד התמחות בהדרכת הורים לילדים על הרצף האוטיסטי, בלוג עצמאי, ארבעה מאמרים ומדיניות פרטיות זמנית.

## הפעלה מקומית
חלצו את כל ה-ZIP ופתחו `index.html` מתוך התיקייה. קישורי CSS, JS ותמונות הם יחסיים ועובדים גם בפתיחה מקומית.

## הכנה לפרסום
1. **דיוקן דניאל**: תמונות `assets/images/hero.webp` ו-`about.webp` הן עיבוד AI שנגזר מהעיצוב המאושר בהשראת תמונת הייחוס, ולא צילומי סטודיו אמיתיים. בדקו שהדיוקן נאמן לדניאל ואשרו אותו לפני פרסום.
2. **פרטי קשר**: הגדירו נתוני עסק מאומתים ב-`assets/js/site-config.js` (WhatsApp / אימייל / שירות טופס). ללא הגדרה הטופס לא שולח מידע. מספרי דוגמה מההדמיה אינם פעילים באתר.
3. **דומיין**: צריך כתובת HTTPS אמיתית ליצירת canonical, Open Graph מלא, structured data, sitemap.xml ו-robots.txt. להרצה בסביבת Node: `SITE_URL=https://yourdomain.co.il node build.mjs` ולהעלות רק את `dist/`. ב-PowerShell: `$env:SITE_URL="https://yourdomain.co.il"; node build.mjs`.
4. **אימות תוכן**: לאשר את הביוגרפיה, התארים, המאמרים, המיקום ואפשרויות המפגש. להחליף או לאשר תמונות ההמחשה, לרבות זכויות שימוש.
5. **משפטי**: להתאים את מדיניות הפרטיות, לוודא נגישות ותיעוד בהתאם לדין ולהתקין מדידת Analytics רק לאחר הגדרות פרטיות והסכמה כנדרש.

## קידום אורגני וחיפוש AI
עמודים נפרדים עם HTML סריק ללא תלות ב-JavaScript, semantic headings, תיאורי מטא, Open Graph ומפת אתר בבניית Production, JSON-LD לפי סוג העמוד, קישורים פנימיים וסריקה מותרת ב-robots.txt. אלה תנאים תומכים, לא הבטחה למקום ראשון או להמלצות של ChatGPT/Gemini. כדאי לבנות בהמשך תוכן מקורי, תיק מקצועי מאומת ואזכורים איכותיים מחוץ לאתר.
