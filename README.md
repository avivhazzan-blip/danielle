# דניאל סביר חזן — אתר הדרכת הורים

אתר סטטי בעברית (RTL), עם HTML נגיש וניתן לסריקה גם ללא JavaScript, CSS רספונסיבי ו־JavaScript מינימלי לשיפורי חוויית המשתמש.

## צפייה מקומית

חלצו את ה־ZIP **כולו**, פתחו את `index.html` מתוך התיקייה, והקפידו ש־`assets/` נשארת לצד הקובץ. דפים פנימיים ייפתחו דרך הקישורים שבאתר. אפשר גם להפעיל שרת סטטי מקומי.

## חובה לבצע לפני העלאה לאוויר

1. **פרטי קשר:** ערכו `assets/js/config.js`. הזינו מספר WhatsApp בפורמט `9725XXXXXXXX` בלי `+`, מספר טלפון, כתובת מייל וקישורים אמיתיים לרשתות החברתיות. בהיעדרם כפתורי הפנייה מפנים לאזור הטופס ומודיעים שפרטי הקשר טרם הוגדרו. **לא הומצאו פרטים.**
2. **שליחת טופס:** הטופס נכתב לשימוש עם **Netlify Forms** (`data-netlify="true"`, טופס עם Honeypot). פרסמו ב־Netlify ואשרו את הגדרות ההודעות/שמירת הטפסים בפאנל הניהול. ב־GitHub Pages או באתר מקומי הטופס *אינו* שולח. אם בוחרים ספק אחר נדרש חיבור טופס אמיתי וסלילה של פרטיות/הסכמה. אל תציגו הצלחה עד לאישור שרת.
3. **המלצות:** שלוש הכרטיסיות בדף הבית הן **מקומות שמורים בלבד**, לא המלצות מקוריות. החליפו בציטוטים שקיבלתם ואושרו לפרסום; הוסיפו דירוג רק אם באמת ניתן. אין להציג תווית "מאומתת" ללא אימות אמיתי.
4. **טקסטים מקצועיים:** קראו, דייקו ואשרו את שלוש טיוטות המאמרים לפני פרסום.
5. **תמונות:** דיוקנאות דניאל באתר נלקחו מההדמיות המאושרות ונוצרו/עובדו באמצעות AI על סמך התמונה שסופקה בשיחה; אלה **אינם צילומי מקור של דניאל**. מומלץ להחליף בצילומי פורטרט אמיתיים באישור בעלת העסק לפני אתר ציבורי, במיוחד מטעמי אמון.
6. **משפט השראה:** משפט ההשראה מוצג ללא ייחוס מחבר, מאחר שלא אומת מקורו. אם רוצים לייחס — יש לבדוק מקור.
7. **דומיין:** לא הומצא דומיין. להלן הוראות להפקת Canonical, OG ו־Sitemap עם דומיין אמיתי.
8. **מסמכים משפטיים:** מדיניות פרטיות, הצהרת נגישות ותנאי שימוש הם טיוטות ושולבו כ־`noindex` עד לאישור והתאמה. חובה להתאים לפרטי העסק, מערכת הטפסים והדין החל; לבצע בדיקת נגישות אמיתית ולא לטעון לעמידה מלאה ללא בדיקה.
9. **כתובת ושירות:** קיים ציון של קריית אונו, **ללא כתובת מדויקת, שעות פעילות או שירות אונליין שלא נמסרו**.

## פרסום עם דומיין וקידום אורגני

צריך Node.js. בתיקייה הראשית:

```bash
node build.mjs https://www.your-real-domain.co.il
```

הפקודה מפיקה את `dist/` לפרסום, כולל `sitemap.xml`, `robots.txt`, `link rel="canonical"` וקישורי OpenGraph מוחלטים. יש להחליף לדומיין **שבבעלותכם בפועל**. אם מריצים ללא כתובת, תקבלו גרסת Preview ללא כתובת Canonical מומצאת.

פרסמו את תוכן `dist/` באחסון סטטי, עדיף Netlify אם משתמשים בטופס. לאחר הפרסום: אמתו דומיין ב־Google Search Console, שלחו Sitemap, הגדירו Google Business Profile אמיתי אם העסק זכאי, ודאגו לתוכן מקורי, אזכורים מקצועיים אמיתיים וקישורים פנימיים.

## מבנה האתר

- `/` — דף בית עם ה־H1 "הדרכת הורים שמתחילה בהבנה, ומאפשרת שינוי"
- `/parent-guidance-kiryat-ono/` — הדרכת הורים בקריית אונו
- `/autism-parent-guidance/` — ליווי הורים לילדים על הרצף
- `/blog/` — בלוג עם סינון ב־JavaScript (כל הכרטיסיות קיימות ב־HTML לפני הפעלת JS)
- `/blog/parent-child-connection/`, `/blog/toddler-tantrums/`, `/blog/sleep-and-routines/` — מאמרים
- `/privacy/`, `/accessibility/`, `/terms/`, `/thanks/` — עמודים משלימים

## עיצוב ואינטראקציה

- Heebo עם fallback למערכת, CSS רגיל ללא ספריית CSS גדולה.
- מרווה, מנטה, שמנת וסלמון במינון נמוך; ללא עיטורי עלים.
- Sticky Header עם תפריט נייד; Sticky Bottom CTA המופיע אחרי הבאנר ומוסתר באזור יצירת הקשר.
- Scroll Reveal מתון, עם `prefers-reduced-motion` ו־HTML זמין ללא JS.
- שאלות נפוצות כ־`<details>` נגישים; מותאם למקלדת.
- תמונות WebP מקומיות; תמונת הבאנר נטענת בעדיפות גבוהה, יתר התמונות בעצלות.

## SEO / AI Search

תוכן נגיש כ־HTML, קישורים אמיתיים, תיאורי Meta ייחודיים, כותרת H1 אחת בכל דף, JSON-LD תואם לנראות, תגיות OG, כלי בנייה ל־Canonical/Sitemap, ו־robots ללא חסימות מיותרות (כולל OAI-SearchBot). אין דרך להבטיח דירוג ראשון בגוגל או המלצה ממערכת AI. עבודה נוספת לאחר הפרסום: מחקר ביטויים ומתחרים, פרסום מאמרים מעמיקים ומקוריים, E-E-A-T, עדכוני תוכן ומדידת תוצאות.
